# Support

Use GitHub Discussions or a clearly redacted issue for installation questions and reproducible defects. Include the Spark Insights version, Python/OS version, command options without local paths or secrets, exit code, and a synthetic fixture when possible.

Do not upload private datasets, API keys, provider errors containing account details, or complete local manifests unless you have reviewed them. Use the private process in `SECURITY.md` for vulnerabilities.

This alpha is provided without decision, financial, legal, medical, or operational assurance. Computed outputs require domain review.
